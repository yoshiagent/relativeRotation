> Long-only Pair Rotation — 利用同產業/同主題股票的相對強弱輪動，找出「相對低估、準備補漲」的股票。

## 🎯 策略核心

### 配對與 Ratio

```
Ratio = StockA 收盤 / StockB 收盤
```

| 配對ID | 主題 | StockA | StockB |
|---|---|---|---|
| P01 | ABF載板     | 南電 (8046)   | 欣興 (3037)   |
| P02 | AI電源/PSU  | 光寶科 (2301) | 台達電 (2308) |
| P03 | AI散熱      | 奇鋐 (3017)   | 雙鴻 (3324)   |
| P04 | CCL         | 台光電 (2383) | 聯茂 (6213)   |
| P05 | AI ODM      | 廣達 (2382)   | 緯創 (3231)   |

### 進場條件（10 項）

1. Ratio 60日 Z-score < -2
2. 低檔翻揚（Z 上升 + Ratio 站回 MA5）
3. 雙週 MA20 皆向上
4. 週 MA20 斜率 > 0
5. 月 K 剛脫離長期整理
6. 週 K Higher Low 結構
7. 日 K 量縮修正 MA20 乖離
8. 修正量 < 上漲量
9. 20 日均量 > 60 日均量
10. 加權指數位於週 MA20 之上

**綜合判定：**
- ✓ 強烈進場：Z<-2 且 ≥8 項
- ○ 適合進場：Z<-1.5 且 ≥6 項
- △ 觀察：Z<-1 且 ≥4 項
- × 不適合：Z≥0 或條件不足

### 風險訊號 / 停止操作

1. Corr(60) < 0.65（警示）/ < 0.5（配對失效）
2. 任一股 MA20 乖離 > 20%（過熱）
3. 任一股週 MA20 轉平/下彎（趨勢失效）
4. 加權指數跌破週 MA20（大盤風險）
5. Ratio 突破 120日布林 + 爆量（結構性脫鉤）
6. 時間停損：20-30 日仍未回歸均值

### 位置判定（儀表板）

| Z-score 區間 | 位置 |
|---|---|
| MA20 乖離 > 20% | 過熱段 |
| Z < -2 | 修正段（低估） |
| -2 ≤ Z < -1 | 重新轉強 |
| -1 ≤ Z < 0 | 主升初段 |
| 0 ≤ Z < 1 | 主升中段 |
| 1 ≤ Z < 2 | 主升末段 |
| Z > 2 | 過熱段（強勢） |

### ⭐ 補漲標記

當 **Z < -1.5** 且 **進場訊號 ≥ 進場/觀察等級** 且 **無停止訊號** → 標記為「即將補漲」。

## 🧮 公式說明

| 指標 | 公式 |
|---|---|
| Ratio | `A_close / B_close` |
| Z-score(60) | `(Ratio - rolling_mean(60)) / rolling_std(60)` |
| 布林通道 | `mean(60) ± 2 × std(60)` |
| Correlation(60) | `corr(A_returns, B_returns)` over 60 days |
| ATR(14) | `mean(True Range, 14)` |
| Vol Regime | `Vol_20 > Vol_60` → 資金進場；否則資金退潮 |
| MA20 乖離% | `(close / MA20 - 1) × 100` |
| Relative Strength(20) | `(A_return_20d - B_return_20d) × 100` |

## 🚦 交易哲學

> 不是預測漲跌，而是尋找「資金輪動造成的相對低估」。
>
> 利用：趨勢 + 波動率差 + 均值回歸 + Relative Strength
> 提升長期資金效率。

**重要原則：**
1. 優先趨勢向上的股票（雙多頭）
2. 避免空頭中的均值回歸
3. 優先月線剛突破整理
4. 優先週線 Higher Low
5. 優先日線量縮修正
6. 避免爆量情緒末升段
7. 避免新聞極度熱門後追價
8. 重視成交量與資金流向
9. 重視法人型慢牛股
10. 核心是 Relative Rotation，而非猜大盤
